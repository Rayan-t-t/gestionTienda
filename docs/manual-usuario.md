# Manual de usuario

Guía rápida para usar el gestor de videojuegos.

## Acceso

Inicia sesión con tu correo y contraseña. Tu rol determina las opciones disponibles. Usa el botón «Carrito», junto a tu saludo, para revisar tus productos y «Cerrar sesión» para salir.

## Catálogo

Consulta los juegos, busca por título, plataforma o género y navega entre páginas. Añade al carrito los títulos disponibles o selecciona una tarjeta para ver sus detalles.

## Carrito y pedido

El carrito se guarda en este navegador para cada cuenta. Ajusta las cantidades y pulsa «Finalizar pedido» para descontar el stock. Es una simulación: no se realiza ningún pago. El descuento se realiza como una operación atómica: si falla algún producto, no se descuenta stock y el carrito se conserva.

## Gestión de juegos (administración)

Las cuentas administradoras pueden crear juegos desde el botón «Crear videojuego», editar desde la fila o el detalle y eliminar tras confirmar. El formulario comprueba que el SKU no esté duplicado.

## Dashboard

El dashboard, disponible para administración, resume total de juegos, stock, valor del inventario y valoración media, y muestra las unidades vendidas por día en los últimos 30 días. Las ventas se guardan en la colección de auditoría de Firestore al confirmar la compra; el histórico empieza con las compras registradas desde esta versión. El gráfico consulta hasta 500 actividades recientes.

## Exportación

Las cuentas administradoras pueden usar «Exportar CSV» o «Exportar PDF» en el catálogo para descargar los resultados de la página visible. El CSV está preparado para abrirse en hojas de cálculo.

## Accesibilidad

Usa Tab y Mayús+Tab para navegar, Enter o Espacio para activar controles y el enlace «Saltar al contenido» para ir directamente al contenido principal. El foco es visible y se respeta la preferencia de movimiento reducido y el tema oscuro del dispositivo.
