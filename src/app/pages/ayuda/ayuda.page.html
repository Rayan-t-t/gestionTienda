Manual de usuario

Guía rápida para usar el gestor de videojuegos.

 Acceso

Inicia sesión con tu correo y contraseña. Tu rol determina las opciones disponibles. Usa la barra superior para cambiar de pantalla y «Cerrar sesión», junto a tu saludo, para salir.

 Catálogo

Consulta los juegos, busca por título, plataforma o género, ordena las columnas y navega entre páginas. Selecciona una fila para ver sus detalles.

 Gestión de juegos (administración)

Las cuentas administradoras pueden crear juegos desde el botón «Crear videojuego», editar desde la fila o el detalle y eliminar tras confirmar. El formulario comprueba que el SKU no esté duplicado.

 Dashboard

El dashboard, disponible para administración, resume total de juegos, stock, valor del inventario y valoración media. Los filtros de plataforma y género actualizan las métricas y gráficos.

 Exportación

Usa «Exportar CSV» o «Exportar PDF» en el catálogo para descargar los resultados de la página visible. El CSV está preparado para abrirse en hojas de cálculo.

 Accesibilidad

Usa Tab y Mayús+Tab para navegar, Enter o Espacio para activar controles y el enlace «Saltar al contenido» para ir directamente al contenido principal. El foco es visible y se respeta la preferencia de movimiento reducido y el tema oscuro del dispositivo.
